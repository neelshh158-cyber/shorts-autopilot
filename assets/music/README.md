# Background music (optional)

Drop royalty-free `.mp3` files in this folder and the renderer picks one at
random per video, mixed quietly under the voice (volume set by
`video.musicVolume` in `config.json`).

Only use tracks you are allowed to monetise. Good sources: the YouTube Audio
Library (download from YouTube Studio), Pixabay Music, or Uppbeat with a
licence. Never use copyrighted songs; Content ID will claim the video.
